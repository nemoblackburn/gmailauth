Test Auth Code AutoFill

Note: This is a test page. The extension will look for real verification codes in your Gmail that match the domain you're testing from.

How to Test

1. Send yourself a test email

  • Send an email to yourself from the same domain as this page (e.g., if testing on localhost, send from Gmail)
  • Include a verification code in the subject or body, like: Your verification code is: 123456
  • The email should be sent within the last 5 minutes

2. Focus on any input field above

  • Click into any of the code input fields
  • If a matching code is found in your Gmail, you'll see the auto-fill popup
  • Click the code to fill it automatically

3. Check domain matching

  • The extension extracts the sender domain (e.g., noreply@github.com → github.com)
  • It compares with the current page domain
  • Codes only appear when domains match

4. Debugging

  • Open DevTools (F12) → Console tab
  • Look for any error messages from the extension
  • Check the extension popup to see connection status
